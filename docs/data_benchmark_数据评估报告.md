## 关键发现（对后续工作的影响）

1. **用户高度集中（最重要）**：前 5 名用户贡献约一半样本，`user_JuHAw` 一人 676 条。同一用户的问题往往是同一主题、强相关，**随机切分会导致同一用户的相似问题跨 train/test 泄漏**。→ 切分必须**按用户分组**（同一用户全部归入 train 或 test 其中一侧）。

2. **答复 `...` 前缀需清洗**：598 条（15%）以 `...` 开头，是导出拼接残留，切分前应去除。

3. **无效样本少量存在**：9 条 <20 字答复、121 条 <5 字提问，评估时可过滤或单独标记。

4. **多轮上下文缺失**：CSV 无会话 id，每条为独立一问一答，部分提问可能依赖上一轮上下文（被折进长问题文本）。评估按单条独立打分即可，但需知此局限。

## 附：建议的切分规则

基于以上发现，train/test 切分应满足：

1. **按用户分组**：同一用户的所有问答不跨池；
2. **清洗 `...` 前缀**与空值；
3. **语义近重复聚簇**：embedding 聚类后同簇不跨池；
4. **分层抽样**：按智慧员工 + 主题分层，test ≈ 300 条（约 7–8%）；
5. **固定随机种子**保证可复现。
